La Mediana
  • Definición: La mediana es el valor que se encuentra en el centro de un conjunto de datos ordenados. Divide el conjunto en dos partes iguales.
  • Datos ordenados: Para calcular la mediana, los datos deben estar ordenados de menor a mayor.
  • Mediana para datos impares: Datos: [50, 20, 40, 10, 30] (desordenados)
    Ordenados: [10, 20, 30, 40, 50]
    Mediana: 30
  • Mediana para datos pares: Datos: [60, 20, 50, 10, 40, 30] (desordenados)
    Ordenados: [10, 20, 30, 40, 50, 60]
    Mediana: (30 + 40) / 2 = 35
